使用说明

无需服务器，浏览器直接查询

1. 填密钥：粘贴 API 密钥（每行一个），点「开始查询」。密钥只在本机使用。

2. 使用记录：选中密钥后点「使用记录」，看近 24 小时的成功/失败/退款记录，费用按官方价格表、1:10 换算人民币。

3. 任务日志：使用记录里点「任务日志」，只看视频模型任务；耗时/进度需站点登录接口。

4. 跨域要求：浏览器直连中转站需要站点允许跨域（CORS）。若提示「Failed to fetch / 跨域失败」，请按 README 给站点加 CORS 头（三个接口都要）。

5. 安装到桌面/主屏幕：用 HTTPS 打开后，Chrome 菜单选「安装」，Safari 选「添加到主屏幕」。

隐私：本页面是公开工具，任何人都能打开，但不会收集你的密钥；密钥只在你浏览器里，直接发给中转站。公共电脑请勿勾选「记住密钥」。
